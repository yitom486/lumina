# ACP 聊天 — 手动 E2E 清单

自动化：`bun run test:ui` 覆盖容器宽度、流式/完成态气泡、工具活动区展示逻辑（mock 数据，不 spawn Agent）。

以下需在 **`bun tauri dev`** 下人工执行（依赖本机 Agent / Bun / Codex，不适合 CI）。

## 前置

- [ ] Agent 设置里 Codex profile 显示 ✓ 或已配置 custom 命令
- [ ] 可选：打开一个视频文件（验证上下文注入不影响 UI）

## 容器与流式

- [ ] 切到「对话」tab，设置栏 / 消息列表 / 输入框左右对齐、同宽
- [ ] 发送问题，流式过程中助手气泡与完成后**同宽**（占满列，非窄条）
- [ ] 流式时可见光标 `▍`，完成后消失

## 思考 / 工具 / 计划

- [ ] 思考展示 =「流式时显示，完成后收起」：流式时可见思考/工具区，完成后只剩最终答案
- [ ] 思考展示 =「始终保留轨迹」：完成后仍可见工具行
- [ ] 思考展示 =「隐藏」：不出现思考区块

## 权限与会话

- [ ] 权限 =「每次询问」：工具调用时出现审批条，批准后继续
- [ ] 「结束会话」后 sessionId 提示消失；再次提问可新建或 resume（同 profile + cwd）
