# UI 工作区手动 E2E 验收

这是**真实桌面窗口**验收，不是 DOM mock 验收。使用 `bun run tauri`、真实 libmpv HWND 和真实 ACP（需要时）；`bun run test:ui` 只能作为渲染回归辅助，不能勾选本清单中的桌面通过项。

## 当前实现边界

- 视频由 libmpv 原生 HWND 绘制；WebView 只负责 sibling 布局和 HTML 控件。
- 普通窗口右侧是列表/文稿/笔记/章节/媒体库/在线侧栏；AI 是独立的右侧 `ChatDock` sibling。
- 打开 AI 时普通侧栏暂不显示；关闭 AI 后恢复普通侧栏。AI 面板保持 mounted，收起不等于结束会话。
- 当前迁移分支的顶部 **AI 对话** 工作区已包含 **AI 观剧流 / 自由聊天** 双 Tab；仍需在真实 Tauri 窗口中分别验证两个 Tab 的数据隔离、工具轨迹和布局行为。

## 前置条件

- [ ] `bun run tauri` 启动成功，窗口可正常调整大小
- [ ] 打开一个有画面的本地媒体；若验证在线源，在线解析和字幕已先单独确认
- [ ] 播放状态至少可在 Playing / Paused 间切换
- [ ] ACP 需要时已按 [`manual-e2e-acp.md`](./manual-e2e-acp.md) 配置并登录
- [ ] 记录窗口尺寸、媒体类型、Agent profile 和失败诊断 code；不要记录绝对路径或账号凭据

## A. 右侧 sibling 工作区

- [ ] 普通窗口打开顶部 **AI 对话**：右侧出现固定宽度工作区，视频区域向左收缩，AI 不覆盖视频画面
- [ ] 工作区标题、消息列表、输入框和设置区域在同一列内对齐；窗口变窄时内容可滚动，不出现横向溢出
- [ ] 点击“收起对话”或按 Esc：右侧 AI 工作区消失，普通侧栏恢复；再次打开时已有会话/消息仍在
- [ ] AI 发送问题期间调整窗口大小：视频和右侧工作区都重排，字幕/控件不漂移到 HWND 上

## B. AI 观剧流 / 自由聊天 Tab

这组检查只在构建确实提供两个 Tab 时执行；找不到入口必须在记录中写“未覆盖”，不能用当前单一 AI 对话入口替代。

- [ ] **AI 观剧流** Tab：显示当前播放锚点、台词/工具活动/富卡片流；播放位置变化后新提问使用新的锚点
- [ ] AI 观剧流中的剧情问题优先使用 Lumina transcript/library 工具；画面问题才按能力调用截图；卡片中的跳转时间来自工具实际返回值
- [ ] **自由聊天** Tab：可进行不依赖当前视频锚点的普通对话；切换 Tab 不把另一 Tab 的草稿、工具活动或错误串进来
- [ ] 两个 Tab 都遵守同一权限、历史和 Agent profile 选择；切换不会把一个 profile 的会话恢复到另一个 profile
- [ ] Tab 切换、收起和重新打开均保持 sibling 布局，任何 Tab 内容都不覆盖 HWND

## C. 普通面板与 AI 的切换

- [ ] AI 打开时，普通侧栏不与 AI 并列抢占同一右侧区域；视频只保留一个明确的 HWND sibling 位置
- [ ] 关闭 AI 后依次切换列表、文稿、笔记、章节、媒体库、在线；每个面板都能打开且不遮挡视频
- [ ] 从普通面板重新唤出 AI：普通侧栏收起，AI 进入同一右侧工作区；不会出现旧的居中/覆盖式面板
- [ ] 普通面板切换不会结束 ACP 会话；若产品版本要求“切换普通面板即关闭 AI”，应确认 AI 按钮状态变为关闭、再打开可恢复原会话，并在备注中写明实际行为

## D. 全屏唤出与退出

- [ ] 普通窗口按 `F` 或点击全屏按钮进入全屏；标题栏和普通侧栏隐藏，视频铺满可用区域
- [ ] 全屏状态把鼠标移到顶部：出现全屏顶部控制区；从这里可以唤出 AI 工作区或退出全屏
- [ ] 全屏唤出 AI 后，AI 仍位于视频 HWND 的 sibling 区域；不以透明 WebView、覆盖式 UI 或居中对话框覆盖视频像素
- [ ] AI 打开时按 Esc 先收起 AI；AI 已关闭时按 Esc 才退出全屏；重复进入/退出不丢失播放状态
- [ ] 全屏底部播放控件自动显隐；打开音量/字幕/音轨菜单时菜单留在 HTML 播放控件区域，不压住 HWND

## E. 权限、历史和 Agent 切换

- [ ] 在 AI 工作区切换权限模式并发起一次工具调用：每次询问能审批，拒绝有业务提示，自动模式不为普通只读工具重复弹窗
- [ ] 打开历史、刷新、切换旧会话、关闭历史；回答进行中不能静默切换或丢失当前回合
- [ ] 结束当前会话后重新提问可新建；关闭/重开工作区不改变当前 profile
- [ ] 切换 Codex / Antigravity / custom 后，Agent 名称、连接状态、消息/工具轨迹和设置同步到新 profile；旧 profile 内容不闪现
- [ ] 未配置 Agent 时 AI 不可用的提示不影响播放、文稿、笔记、章节和普通侧栏

## F. HWND 不遮挡检查

必须在至少一个普通窗口尺寸、一次窗口 resize、一次全屏和一次 AI 打开状态下检查：

- [ ] 视频像素只出现在明确的播放矩形内；右侧 AI、普通侧栏、标题/顶部控制、底部播放条均不绘制到该矩形上
- [ ] 在视频四角和右边界移动鼠标，点击 AI/普通控件时不会误触发视频控件，也不会看到 HTML 内容穿透到视频上
- [ ] 调整窗口大小、切换普通侧栏、收起/打开 AI、进入/退出全屏后，HWND 仍与视频矩形对齐，无黑边错位、残留旧画面或点击区域漂移
- [ ] 观察日志/开发者工具时只记录布局或业务诊断；不以 canvas 假画面、`<video>` 或 DOM 截帧来判定 native playback 通过

## 未覆盖项

- 双 Tab 的 DOM/组件测试不等于真实 Tauri 验收；仍需记录真实窗口中的切换、布局、权限、历史和 HWND 结果。

- 本清单不验证生产实现内部的 FFI pointer、窗口句柄数值或 Agent stderr；这些属于实现细节，应通过业务结果和脱敏日志诊断。
